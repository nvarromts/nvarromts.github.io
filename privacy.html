Política de privacidad

Esta política describe cómo tracker usa los datos de Google.

Uso de la API de Gmail

tracker usa la API de Gmail únicamente con el permiso https://www.googleapis.com/auth/gmail.send, para enviar informes de precios por correo al propio usuario.

Datos que no se tratan

tracker no lee, no almacena y no comparte correos electrónicos ni ningún otro dato de la cuenta de Google.

Terceros y publicidad

No se comparte ningún dato con terceros y no se muestra publicidad.

Revocar el acceso

Puedes retirar el acceso de tracker a tu cuenta de Google en cualquier momento en https://myaccount.google.com/permissions.

Contacto

Para cualquier consulta sobre esta política: github.com/nvarromts.
